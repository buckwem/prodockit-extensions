# Zensical authoring

Phase 4 reconciles the authoring surface documented by Zensical with the
underlying Markdown extensions already exercised in this catalogue. A single
canonical output may satisfy both layers when the authoring feature is the
documented use of an extension covered in Phases 2 or 3.

- [Layout and integrations](layout-and-integrations.md) covers front matter,
  configured extensions, buttons, grids, images, tooltips, and macros.
- [Diagrams](diagrams.md) covers Mermaid source, website output, and the static
  vector fallback used in the PDF.
- Existing canonical specimens continue to cover admonitions, code blocks,
  content tabs, data tables, footnotes, formatting, icons and emojis, lists,
  and mathematics.

## Directives coverage decision {: #directives-waiver }

[Zensical Directives](https://zensical.org/docs/authoring/directives/) is
currently early-access software distributed as a separate Zensical Spark
wheel. The public test environment cannot install or redistribute that wheel,
so the ledger records an explicit waiver rather than claiming unexecuted
coverage. The entry can become an implemented specimen when Directives is part
of the supported public installation.
