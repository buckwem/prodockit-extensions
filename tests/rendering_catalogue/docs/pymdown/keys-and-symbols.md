# Keys and symbols

Reference: [Zensical's supported Python Markdown Extensions](https://zensical.org/docs/compatibility/markdown/python-markdown-extensions/)

## Keys { #keys }

### Source

```text
Press ++ctrl+alt+delete++ to review the key combination.
```

### Rendered result

Press ++ctrl+alt+delete++ to review the key combination.

The individual keys and separators must remain visually distinct in both
outputs.

## SmartSymbols { #smartsymbols }

### Source

```text
(c) (tm) 1/2 --> <--
```

### Rendered result

(c) (tm) 1/2 --> <--

The source sequences must become the corresponding copyright, trademark,
fraction and arrow symbols.
