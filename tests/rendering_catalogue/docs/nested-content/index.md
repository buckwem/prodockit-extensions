# Nested content

Nested rendering is a dedicated coverage area. It will grow whenever a new
capability is brought into scope rather than remaining a fixed regression
fixture.

The matrix will use representative, risk-based combinations of containers and
embedded features. Containers include lists, blockquotes, admonitions,
details, content tabs, grids, Markdown in HTML, tables, captions, footnotes and
directives. Embedded content includes anchors, links, images, highlighted
code, abbreviations, keys, mathematics, Mermaid diagrams, citations,
cross-references, glossary terms and index terms.

Each catalogue entry must eventually require an appropriate nested specimen or
record why nesting is not meaningful. Configuration-only entries can inherit
the decision made for their parent extension.

Phase 1 records that contract. The reviewed specimen matrix is added in a
later phase.
