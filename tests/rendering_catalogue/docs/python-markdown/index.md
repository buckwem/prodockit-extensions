# Built-in Python-Markdown extensions { #python-markdown }

Zensical supports eight built-in Python-Markdown extensions. Each extension
has a separate review page with its source and rendered result.

1. [Abbreviations](abbreviations.md)
2. [Admonitions](admonitions.md)
3. [Attribute lists](attribute-lists.md)
4. [Definition lists](definition-lists.md)
5. [Footnotes](footnotes.md)
6. [Markdown in HTML](markdown-in-html.md)
7. [Table of contents](table-of-contents.md)
8. [Tables](tables.md)

Configuration options that materially change the table of contents are also
recorded on its review page. Representative combinations appear in the
[nested-content specimen](../nested-content/python-markdown.md).
