# Multiple long footnotes { #multiple-long-footnotes }

This specimen combines a full page of prose with several footnotes whose text
wraps over multiple lines. Review the PDF to confirm that every reference is
paired with a complete, legible note and that the footnote area does not clip,
overlap or lose text when it becomes crowded.

the inline marker can be reviewed within a realistic sentence rather than in
